# Evidence Taxonomy

Classify materials by proof role. A single screenshot can have more than one role, but record the exact claim it supports.

## Core Roles

| Role | What it proves | Typical assets | Use in carousel |
|---|---|---|---|
| Subject / identity | Who the story is about and why the viewer should care | portraits, public profile screenshots, intro post | hero, credibility, emotional entry |
| Before state | Starting point before the intervention | old bio, low follower count, weak offer page, empty community | tension, contrast |
| Result number | A measurable outcome | payment screenshots, revenue dashboard, follower count, conversion metric | hook, proof slide |
| First proof | Earliest result or first visible win | first message, first sale, first application | "this started working" slide |
| Community proof | Demand, audience response, group activity | Telegram/community screenshots, comments, replies | social proof |
| Process proof | What was done to produce the result | stories, warm-up sequence, profile changes, course modules | mechanism slide |
| After state | New state after work | updated profile, larger audience, stronger offer, new dashboard | before/after or final proof |
| CTA / next step | What the reader should do | link, DM keyword, lead magnet, booking path | last slide |
| Consent / rights | Permission to use person, name, photo, testimonial, screenshots | written approval, screenshot of consent, message timestamp | separate artifact, not a visual proof |

## Claim Gate

For every claim, write one of:

- `VERIFIED` - direct evidence is visible and named.
- `SUPPORTED BUT INDIRECT` - evidence supports the direction, not the exact wording.
- `PENDING` - user says it, but the material is missing.
- `EXCLUDE` - cannot be used safely or ethically.

Use exact phrasing for money, dates, follower counts, screenshots, and testimonials. If the strongest verified proof is smaller than the strongest verbal claim, build the hook from the verified proof.

## Consent Gate

Before public use, record consent separately for:

- name or identifiable handle;
- face/photo;
- private screenshots or messages;
- testimonial or review;
- revenue/payment/business data;
- third-party client/customer data.

Do not treat "the client approved the carousel" as consent from the person featured in the carousel.
