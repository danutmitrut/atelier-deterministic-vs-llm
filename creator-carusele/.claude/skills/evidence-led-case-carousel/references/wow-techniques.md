# WOW Technique Catalog

Use this when selecting the visual architecture. The point is not decoration; each technique must match the material and the carousel type.

The catalog is derived from the 2026-09-22 carousel research, the reference examples, and verified public carousel examples from Buffer/SwipeVault/SlideDrift-style research. Do not copy external designs or content; reuse the mechanism.

## Techniques

| Technique | Use when | Material needed | QC risk |
|---|---|---|---|
| Continuous panorama across slides | big idea, journey, system map | one wide key visual or generated scene | keep final text local/editable |
| Dominant editorial photo | personal story, founder/client story, culture | real photo and usage rights | check other people in frame |
| Data reveal / huge number | result, contrast, before/after, market insight | verified number, period, source | number without context becomes clickbait |
| Screenshot + zoom + annotations | case study, audit, proof, review | screenshots, redaction, consent | identifiable screenshots need permission |
| Handwritten annotations | expert teardown, "look here" proof | screenshot/photo/diagram plus 2-4 notes | too many notes create noise |
| 3D object / mockup | SaaS, AI tool, abstract workflow | generated object, interface frame, product metaphor | not proof; only visualizes idea |
| Before/after split | transformation, redesign, result | comparable before/after assets | do not imply causality without evidence |
| Collage + texture | personal/emotional story, event, backstage | photos, fragments, objects, paper texture | too many elements hurt readability |
| Slide-to-slide progression | tutorial, framework, process | clear sequence | each slide must justify the next swipe |
| Case file / evidence dossier | testimonials, commercial results, B2B case | screenshots, metrics, timeline, consent | personal data and consent are gates |
| Summary/save slide | educational carousel finale | 3-5 key points | should be useful as a standalone screenshot |
| CTA card | end of series | one action | do not mix multiple CTAs |

## Type-to-Technique Defaults

### Review / Success Story

Best techniques:
- case file / evidence dossier;
- screenshot + zoom + annotations;
- data reveal / huge number;
- before/after split;
- community proof collage.

Good references from research:
- Passionfroot + Superhuman case study pattern;
- Mad Over Marketing fact/story pattern;
- Buffer data visualization pattern.

### Useful Explainer

Best techniques:
- continuous panorama;
- slide-to-slide progression;
- diagram/process map;
- 3D object/mockup for abstract workflow;
- summary/save slide.

Good references from research:
- Jay Clouse step-by-step guide pattern;
- Alex Smith strategy phrase pattern;
- Buffer best-time data carousel pattern;
- SlideDrift swipe-file method: save mechanisms, not designs.

### Personal Story

Best techniques:
- dominant editorial photo;
- personal timeline;
- collage + texture;
- one quote/thought per slide;
- behind-the-scenes proof.

Good references from research:
- Buffer employee/company culture carousel pattern;
- behind-the-scenes carousel use case;
- micro-interview cards.

## Default vs WOW Gate

Before delivery, compare the contact sheet against a "default" carousel failure mode:

- same background on every slide;
- uniform dark cards;
- too much empty space;
- no visible proof;
- no visual progression.

If the new contact sheet does not visibly beat that baseline, revise architecture before polishing.
